# グローバル地震マッピングシステム v2.0
## 完全機能版 - 使用ガイド

---

## 🎯 概要

本システムは、1995年～2026年の**日本国内7件 + 海外10件 = 計17件**の震度6以上の地震を可視化したインタラクティブマッピングツールです。

**被害統計を完全収録**:
- ✅ 死者数・負傷者数
- ✅ 建物全壊・半壊数
- ✅ 経済損失額（推定）

---

## 📦 ファイル構成

```
earthquake_global_map_v2.html      ← メインアプリケーション（必須）
earthquake_global_data.json        ← データセット（参考用）
global_earthquakes_damage_report.md ← 詳細ドキュメント
```

### 使用方法

**1. ブラウザで開く**
```bash
# ブラウザで直接オープン
開く: earthquake_global_map_v2.html
```

**2. ローカルサーバーで実行（推奨）**
```bash
# Pythonがある場合
python -m http.server 8000

# Node.jsがある場合
npx http-server
```

## 🗺️ 使い方（基本）

### ステップ1: マップを開く
```
1. earthquake_global_map_v2.html をブラウザで開く
2. スプラッシュ画面が3秒で消える
3. グローバルマップが表示される
```

### ステップ2: フィルターを設定
```
サイドバー（右側）で以下を設定:
- 地域: 全世界 / 日本 / 海外
- 年度: 1995年～2026年から選択
- 最小M: スライダーで調整
```

### ステップ3: 地震マーカーをクリック
```
地震マーカー（円）をクリック
  ↓
ポップアップで被害情報が表示
  ↓
詳細を確認
```

### ステップ4: 共有・印刷
```
ヘッダーボタンで:
- 📤: SNSで共有
- 🖨️: 印刷
- 🌙: テーマ切替
```

## 🎚️ フィルター詳細

### 地域フィルター
| 選択肢 | 表示内容 |
|--------|---------|
| **全世界** | 日本 + 海外全地震 |
| **日本国内** | 日本の7件のみ |
| **海外** | 海外の10件のみ |

### 年度フィルター
- 1995年: 阪神大震災
- 2004年: スマトラ沖大地震
- 2011年: 東日本大震災
- 2016年: 熊本地震
- 2023年: トルコ・シリア地震
- 2024年: 能登半島地震
- 2026年: 熊本県地震（最新）

### マグニチュード フィルター
```
0.0  ← スライダーで調整 → 10.0
（入力した値以上の地震が表示）
```

## ⚙️ 技術仕様

### 使用ライブラリ
- **Leaflet.js 1.9.4** - 地図表示
- **Chart.js 3.9.1** - グラフ表示
- **CSS Variables** - テーマ対応

### ストレージ
```
LocalStorage に保存:
- theme (light/dark)
- filterSettings
- userPreferences
```

### データ形式
```json
{
  "domestic": [
    {
      "date": "YYYY-MM-DD",
      "location": "場所",
      "lat": 緯度,
      "lng": 経度,
      "mag": マグニチュード,
      "casualties": { "deaths": 死者, ... },
      "economic_loss": 経済損失（単位:ドル）
    }
  ],
  "international": [...]
}
```

## 🆘 トラブルシューティング

### マップが表示されない
```
→ ブラウザをリロード（F5キー）
→ キャッシュをクリア
→ 別のブラウザで試す
```

### マーカーが表示されない
```
→ フィルター設定を確認
→ 「🔄 更新」ボタンで再読み込み
→ ブラウザコンソールで エラーを確認
```

### 共有できない
```
→ SNS アカウントにログイン
→ ポップアップブロック設定を確認
→ リンクコピーで共有
```

### テーマが保存されない
```
→ ブラウザの localStorage を有効化
→ プライベートブラウジングモードを終了
→ 別のブラウザで試す
```
